# 常见问题

## C·Path 是在线判题网站吗？

它是浏览器本地运行的学习平台。代码在沙箱 Worker 中编译执行，样例和本地测试会比较真实 stdout。静态网站无法提供服务器隐藏测试，因此“本地测试通过”不等于防作弊的 Online Judge Accepted。

## 第一次点击运行为什么较慢？

C 运行器按需加载。第一次运行会下载并初始化 xcc WebAssembly 运行时，之后会使用浏览器缓存。

## 我的代码和学习记录保存在哪里？

草稿、进度、收藏、复习标记和最近练习保存在当前浏览器的 LocalStorage。首页可以导出和导入学习记录；项目没有账号系统或跨设备同步。

## `scanf` 应该把输入写在哪里？

将输入数据写进练习页的“自定义输入”框，例如 `3 5`。程序通过 stdin 读取这段内容。

## 为什么题库中还有来源档案？

38 条 C_PAT 记录保留了真实路径和标题，但原始题面、测试和发布授权并未完整核验。它们单独放在“来源资料档案”中，不计入正式原创练习数量。

## 运行器支持哪些 C 代码？

适合短小的 C99/C11 入门程序，包括 stdio、变量、条件、循环、数组、函数和字符串。复杂 GCC 扩展、超长程序和部分标准库行为可能不兼容。

## 如何报告问题？

请提供页面 URL、浏览器和设备、复现步骤、预期与实际结果，以及是否能在无痕窗口复现。涉及题库时，请同时说明题目 ID 和测试输入。
