# 新手使用指南

## 你要做什么

C·Path 把学习拆成四步：读懂题目、写一版代码、运行并观察输出、提交本地测试。

## 第一次练习

1. 打开首页的“立即开始练习”。
2. 阅读输入格式和公开样例。
3. 在编辑器写 C 程序。
4. 如果程序需要数据，把数据填入“自定义输入”。
5. 先点击“运行代码”，再点击“运行样例”。
6. 所有本地测试通过后，使用“下一道原创练习”。

## 运行结果怎么读

- 编译失败：代码还没有生成可执行程序，先看编译诊断。
- 运行失败：程序启动了，但返回了错误或触发运行问题。
- 运行超时：通常是循环无法结束。
- 本地测试通过：当前代码通过了公开或本地配置测试，不代表服务器隐藏测试。

代码和学习记录保存在当前浏览器。定期从首页导出记录，可以降低清理浏览器数据造成的损失。
